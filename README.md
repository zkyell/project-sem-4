# project-sem-4
This is a Semester 4 project for the Web Programming course.
This project is a dynamic e-commerce website focused on laptop sales and computer repair services. The website allows users to browse and purchase laptops through a shopping cart and checkout system. In addition, it provides a computer repair service feature where users can submit their devices for repair and manage their service queue.

The project includes essential e-commerce features such as product listings, shopping cart, checkout, and order management, as well as a service queue system for computer repairs.
